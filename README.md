# doublechckr

Gmail checks that you attached something. doublechckr checks that you attached the right thing.

A Chrome extension that reads your attachment the moment you add it and checks it against your email before you hit Send.

## Setup

1. Go to `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and pick this folder.
2. Get a Gemini API key at [aistudio.google.com](https://aistudio.google.com).
3. Click the doublechckr icon in Chrome's toolbar, paste the key, and click **Save & test**.
4. Reload Gmail.

Try it with the fake files in `demo/`.
